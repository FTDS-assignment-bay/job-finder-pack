# :wave: FTDS Job Finder Pack

Welcome to the FTDS Job Finder Pack: Preparing for Technical Test. In today's competitive job market, securing a role in the field of data jobs requires not only a strong foundation but also the ability to excel in technical test. This course is tailored to provide you with the advanced skills and knowledge you need to not only pass these test but to stand out among the candidates.

## 🤓 Course overview and learning outcomes

This self-paced elective program is designed to be a bridge between your foundational data jobs knowledge and the real-world requirements of data job test. We will delve into advanced topics, from machine learning and deep learning to statistical analysis and data visualization, equipping you with the tools and techniques that are in high demand by employers. 🚀

## 📝 Course Structure

Each folder, we will focus on specific domains and gradually build your expertise. You will have opportunities to apply your knowledge through hands-on projects.

- DA: Contains Data Analysis related problems, from data cleaning, data wrangling, data visualization, and statistical analysis. In this folder, you will mostly using SQL and Python to solve the problems and make a report.
- DS: Contains Data Science related problems, from machine learning, deep learning, and data visualization. In this folder, you will mostly using Python to solve the problems and make models.
- DE: Contains Data Engineering related problems, from data cleaning, data wrangling, data visualization, and statistical analysis. In this folder, you will mostly using SQL and Python to solve the problems and end to end Data Engineering pipeline.
- Others: Contains other data related problem to help you prepare for the technical test and to ehance your data related skills.

## 📚  Resources

Throughout the pack, you will have access to real-world company problems and real datasets from company. This technical test problems are real problem that been used to assess FTDS alumni, compiled in this form of job finder pack.

At the end of this program, you will not only have the technical skills required for data related positions but also the confidence to excel in the competitive world of technical test. We are excited to embark on this journey with you and help you achieve your career goals in the field of data jobs.

Let's get started and prepare you for a successful career in data jobs!
