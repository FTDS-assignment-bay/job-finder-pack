This folder contains problem solving related to data analytics tools, which are respectively:
1. `DA_1.xlsx` is an SQL-DQL-8-problems exercise that contains 3 tables that provided in different sheets. Additionally, You need to check the data (do simple exploration) to find the anomaly on data in order to finish the question number 7. Finally, you have to make a dashboard using Tableau using those 3 provided tables in order to finish the problem number 8.
2. `DA_2.xlsx` contains SQL-DQL-2-problems exercise that contains 2 tables in different sheets.
3. `DA_3.xlsx` same with `DA_1.xlsx` but only contains 7 exercises.
4. `DA_4.xlsx` similar to `DA_1.xlsx` and `DA_3.xlsx` but with different dataset.
5. `DA_5.docx` contains 2 questions. The first one is about business knowledge and the second one is about SQL query.
